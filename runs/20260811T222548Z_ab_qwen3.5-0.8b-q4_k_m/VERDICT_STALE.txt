WHY THIS IS A SIBLING FILE AND NOT AN EDIT
------------------------------------------

archive disagree with the code that produced it, and a future reader could not tell whether
the file was written that way or corrected later. It would also destroy the evidence that
the rubric changed, which is the more useful fact: a rule was tightened because a measured
transcript showed the old one was insufficient.

Same reasoning as FIDELITY_STALE.txt in this directory, which retires the LATENCY from this
run while leaving its behavioural findings standing. This marker retires the VERDICT LABEL
while leaving the emission count standing.

before the amendment. COMPETITION.md section 9f-bis-exec item 3 records that this
candidate-fail stands regardless of composite membership.
